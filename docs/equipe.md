## Branches e entregas

- `main`: versão estável, atualizada por merge da `dev`.
- `dev`: desenvolvimento; todo código é enviado primeiro aqui.
- Tags de entrega: `entrega-av1` e `entrega-av2`, criadas no commit final de cada fase.
- Padrão de commits: `feat:`, `fix:`, `docs:`, `chore:`, `test:`. Cada integrante deve ter commits próprios.

## Uso de inteligência artificial

Registro do uso de IA pela equipe. Qualquer pessoa que usar IA deve acrescentar uma linha com honestidade; o professor pode perguntar na apresentação.

| Ferramenta | Uso | Etapa |
| ---------- | --- | ----- |
| Claude (Anthropic) | Leitura do repositório e redação da documentação (README e `docs/`) com base no código | Documentação (AV2) |
| ChatGPT (OpenAI) | Apoio ao desenvolvimento e ao estudo, usado pela equipe | Desenvolvimento (AV1 e AV2) |
| Gemini (Google) | Apoio ao desenvolvimento e ao estudo, usado pela equipe | Desenvolvimento (AV1 e AV2) |

O README original do frontend registra que a extensão do Totem foi feita com auxílio de IA. Para a apresentação, cada integrante deve saber dizer qual ferramenta usou e em qual parte.

Todo código gerado com apoio de IA foi, ou deve ser, revisado, entendido e testado por quem o integrou.
